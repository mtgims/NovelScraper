# Optional: NVIDIA GPU (CUDA) acceleration for local TTS (Kokoro).
#
# The plain `onnxruntime` in requirements.txt is CPU-only (RTF ~1.2x on this
# hardware = slower than playback). This swaps in the CUDA build + CUDA 13 /
# cuDNN 9 runtime libraries as pip wheels (no system CUDA toolkit needed),
# which runs Kokoro on the GPU at RTF ~0.03x (~35x faster; a chapter in ~1s).
#
# Prerequisites:
#   - A working NVIDIA driver — `nvidia-smi` must succeed. If it reports a
#     "Driver/library version mismatch", reboot first.
#   - onnxruntime-gpu 1.27 (the only build with cp314 wheels) targets CUDA 13 +
#     cuDNN 9. Older CUDA-12 onnxruntime has no Python 3.14 wheels.
#
# Install (from backend/, inside the venv):
#   .venv/bin/pip uninstall -y onnxruntime
#   .venv/bin/pip install -r requirements-gpu.txt
#
# Then just run (auto-detects the GPU; CPU fallback is automatic):
#   ./start.sh
# Confirm it bound the GPU:  GET /tts/voices  ->  "device": "cuda"
#
# NOTE ON LAYOUT: these wheels install the .so files under nvidia/cu13/lib,
# which onnxruntime's own loader doesn't search — app/tts.py._preload_cuda_libs()
# dlopens them at startup so `import onnxruntime` resolves. No LD_LIBRARY_PATH
# needed. If you bump onnxruntime-gpu to a CUDA-12 build, use the -cu12 wheels
# instead and this preload still works (it globs nvidia/*/lib generically).

# cuDNN 9 for CUDA 13 is only published on NVIDIA's own package index:
--extra-index-url https://pypi.nvidia.com
