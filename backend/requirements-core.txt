# Runtime dependencies for the deployed container image.

# No server-side TTS: clients synthesize audio themselves (phones via their OS
# voices, desktops via WebGPU), so `kokoro-onnx`/`onnxruntime` are intentionally
# omitted — that keeps the image small and dodges ARM wheel pain. `tts.available()`
# degrades to false when kokoro isn't installed, and the frontend falls back to the
# client engines automatically.
#
# Test-only deps (aiohttp, httpx) are excluded — verified no runtime imports in
# backend/app/. For local development WITH server TTS, use requirements.txt instead.
